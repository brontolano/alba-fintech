"Bangun aplikasi web mobile-first (PWA) untuk Sistem Manajemen Keuangan Institusi (Pesantren) bernama ALBA-APPS.

Sistem Desain:

Tema: Enterprise Finance, Modern, Profesional.
Warna: Navy (#1E3A5F) sebagai warna utama, Emerald (#10B981) untuk pendapatan/sukses, Rose (#EF4444) untuk pengeluaran/bahaya, dan Amber (#F59E0B) untuk peringatan/tunggu.
Tipografi: Gunakan font 'Inter' untuk keterbacaan tinggi dan 'JetBrains Mono' untuk angka/nominal uang agar sejajar sempurna (tabular).
Gaya UI: Soft UI Evolution dengan dimensional layering (shadow halus dan card-based layout).
Struktur Pengguna & Dashboard:

Pimpinan: Dashboard eksekutif dengan ringkasan saldo gabungan 3 unit (Kantor, Kantin, Koperasi), grafik perbandingan performa unit, dan modul persetujuan (approval) transaksi.
Manager Unit: Dashboard spesifik unit dengan pemantauan stok kritis (untuk Koperasi/Kantin) dan pengajuan anggaran.
Staff Unit: Antarmuka input transaksi cepat (POS-style) dan pelacakan status dokumen (Draft/Submitted).
Fitur Utama (MVP):

Buku Besar Digital: Pencatatan transaksi real-time dengan saldo berjalan otomatis.
Input Transaksi Detail: Form yang mencakup Tanggal, Unit, Jenis (Debit/Kredit), Metode (Tunai/Transfer), dan fitur unggah foto bukti transaksi.
Modul Rekonsiliasi: Fitur stor ke pimpinan dan validasi saldo fisik vs digital.
Navigasi: Gunakan Bottom Navigation Bar dengan 5 menu utama: Beranda, Transaksi, Persetujuan, Laporan, dan Rekonsiliasi.
Teknologi: React 18, Tailwind CSS, Lucide Icons untuk set ikon yang konsisten, dan pastikan layout tidak terpotong pada posisi vertikal (responsive)."**

Tips Tambahan:
Jika Anda ingin membangun halaman tertentu secara spesifik, Anda bisa menambahkan instruksi tambahan di akhir prompt, misalnya:

"Buatkan halaman Rekonsiliasi yang menampilkan daftar setoran dari 3 unit berbeda yang menunggu verifikasi pimpinan."
"Buatkan halaman Splash Screen dengan nuansa modern digital dan ilustrasi 3D isometrik tentang digitalisasi keuangan syariah."
